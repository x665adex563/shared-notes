#python #網頁開啟影片 #影片預覽圖 #精靈圖

要讓軟體執行 影片預覽圖功能的話，就要自己安裝ffmpeg

1.到網站下載 ffmpeg-git-essentials.7z 後，解壓縮在不會動到的地方 (不用安裝)
https://www.gyan.dev/ffmpeg/builds/

2.對 "本機" 右鍵 > 內容 > 進階系統設定 > 進階 > 環境變數 > 使用者變數的Path > 
編輯 > 新增 > 編輯(選擇自己安裝的資料夾\bin) (裡面包含三個.exe檔) > 沿路按確定出來

3.把CMD視窗關掉後，打開CMD視窗輸入 ffmpeg -version 就會跳出版本 (代表成功了)

4.這樣就好!

如果要精靈圖功能 (就是把自動把很多小圖片拚到一個大圖片裡省電腦容量)
CMD 執行 pip install pillow (安裝pillow)
