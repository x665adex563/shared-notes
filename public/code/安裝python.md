安裝python

背景設定
1.到 python 官網 下載+安裝
https://www.python.org/downloads/

2.到 pycharm 官網 移下來 下載+安裝 "社群版" (安裝選項全打勾)
https://www.jetbrains.com/pycharm/download/?section=windows

3.開啟pycharm，左上角 File > Settings... > Project: pythonProject > Pythoninterpreter的框框 > show all > 按左上角+ > 選Virtualenv Environment > 按Apply > ok > 就會自動安裝好東西 讓程式能正常運行

4.打開終端機，分別安裝下列三個套件
pip install requests
pip install beautifulsoup4
pip install lxml

可以用 bing ai 自動生成程式碼
yt網頁抓圖片代碼教學 https://www.youtube.com/watch?v=1PHp1prsxIM
